Pagination

tokens/components/pagination.tokens.json · generated — the CSS below is generated from the same resolved tokens driving every preview on this page, not hand-copied. Colors are CSS custom properties, not literal hex.

First/last always visibleReplaces the old double-arrow jump-to-first/jump-to-last buttons — page 1 and the last page are always real, clickable numbers, never collapsed behind the ellipsis, so clicking them does the same job the extra arrows used to.
Active pagefill.primary bg + text.onFill label — same fill as the primary button, not a new color.
Hoverfill.neutralHover — reused from the secondary button's own hover fill for the same subtle-gray feedback.
SizeOne size only, 32px items — a compact utility control for tables/lists, not something that needs sm/base/lg the way button/input/select do.
Rows per pageNot a new dropdown style — this literally renders component.select's sm size, so it stays pixel-identical to the real Select component as that one evolves.

Page ranges

The range-collapsing logic is a real algorithm (current ± 1 sibling, first/last pinned, the rest collapsed into one ellipsis per side), not four hand-typed examples — these are just its output at different current-page positions.
