Search

tokens/components/search.tokens.json · generated — the CSS below is generated from the same resolved tokens driving every preview on this page, not hand-copied. Colors are CSS custom properties, not literal hex.

FillA filled field: fill.neutral (surface-4), no border at rest — deliberately NOT the recessed surface-0 + surface-6-outline of Input/Select. A border appears only on focus.
HoverAdds a 12% lighten layer over the surface-4 fill (the fill stays surface-4; lighten.2 composites on top) — the sportsbook hover overlay, not a border change.
Sizessm 32px / base 40px / lg 48px — same grid, but no floating label at any size. Value/placeholder is 16px throughout (Safari-zoom-safe).
Clear buttonThe trailing × renders once there's a value — a ghost icon button: transparent at rest, filling with the lighten wash and whitening the × on hover, like the ghost Button (not blue-on-hover).
Statesdefault / hover / focus / populated / disabled — no error state; a search box has no validation concept the way a form input/select does.
