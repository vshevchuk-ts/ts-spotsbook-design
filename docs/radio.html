Radio

tokens/components/radio.tokens.json · generated — the CSS below is generated from the same resolved tokens driving every preview on this page, not hand-copied. Colors are CSS custom properties, not literal hex.

Native inputA real <input type="radio"> stays in the DOM, visually hidden (clip-rect, not display:none) — grouping via matching name, keyboard, forms, screen readers all work for free.
Single size20px circle, 8px dot — no sm/base/lg grid, same rationale as Checkbox.
Never fully fillsUnlike Checkbox, checked only recolors the outline and shows a small inner dot — both fill.primary, the circle background stays surface.default. Plain CSS circle, not an icon; every reference checked (Radix/MUI/Ant/Material) draws it this way.
Statesdefault / hover / focused / checked / checked+hover / disabled / disabled+checked. No error state — not asked for.
GroupsRadioGroup composes plain Radio items sharing one name under an optional heading + helper text, vertical or horizontal — no group-level error state.
