Counter

tokens/components/counter.tokens.json · onPrimary + onNeutral variants · generated — the CSS below is generated from the same resolved tokens driving every preview on this page, not hand-copied. Colors are CSS custom properties, not literal hex.

ScopeTwo surface variants exist so far — one per button variant's fill. A standalone counter for plain page surfaces (nav badges, list rows) is deferred until a real use case needs it.
SizingShared by both surfaces — mirrors button's sm/base/lg 1:1, height = the same dim step as that size's iconSize (16/20/24px), so the pill lines up with the icon beside it.
On PrimaryOn the orange active fill: inactive → lighten-2 (12% white) wash + white text; active → white pill + dark text.
On NeutralOn a neutral surface: inactive → lighten-2 wash + white text; active → the active colour (orange) pill + dark text, so it pops against the grey.

CSS

One base .counter class, a shared --sm/--base/--lg size modifier, and --onPrimary/--onNeutral combined with --inactive/--active for color.

:root {
  --tok-lighten-2: rgba(255, 255, 255, 0.12);
  --tok-text-for-active-bg: #11141C;
  --tok-fill-contrast: #FFFFFF;
  --tok-text-default: #FFFFFF;
  --tok-fill-active: #FB8C33;
  --tok-fill-neutral: #3E4351;
  --tok-family-sans: 'Rubik', sans-serif;
}

.counter--onNeutral.counter--inactive { background: var(--tok-lighten-2); color: var(--tok-text-default); }
.counter--onNeutral.counter--active { background: var(--tok-fill-active); color: var(--tok-text-for-active-bg); }
