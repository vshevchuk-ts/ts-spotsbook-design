Mobile betslip

Mobile betslip

The betslip as a real bottom Drawer, assembled strictly from the real design-system components. It opens on load; close it (× / Escape / tap outside) and reopen with the button. Switch the Tabs (Single / Multi / System) to see the different card sets and footers.

Which component is which

  • Container — real Drawer (drawer--bottom, native <dialog> + backdrop + slide-in).
  • Count "3" — real Counter (onNeutral / active) — a rounded pill, not an oval.
  • Single / Multi / System — real underline Tabs, clickable; each swaps the card set + footer.
  • Selection cards — Bet card --compact (Multi / System) and --amount with a per-selection stake (Single). LIVE = real Badge; odds = real Odds (the first flashes + counts up).
  • Stake — real Input lg / --action with the real Max Button inside.
  • System Combination — real Select lg.
  • Total odds / stake / win — Summary rows (total odds = Odds movement).
  • Place bet — Button twoRow / primary; Clear all — Button ghost / sm.

Scaffolding (not components)

  • Which panel/footer shows per tab, and the editable stake <input>.

Open

  • Suspended / error selection states; freebet toggle & bonus rows.
