Mobile betslip

A multi (combo) betslip for the mobile app — built from the Turbo Sportsbook tokens. Every colour on the screen resolves from tokens/semantic/color.tokens.json into a --tok-* variable; nothing is a literal hex. This is a screen prototype for the betslip task, not a component contract — iterate on it here before it goes into the app.

What's on the screen

  • Header — title + live selection count (fill.active pill), Clear all.
  • Bet-type tabs — Single / Multi / System, underline style with outline.active.
  • Selection cards — surface.card on surface.page; live tag uses the accent tint (bg.accent / text.accent); odds that drifted up show in text.positive.
  • Footer — sticky combo block: stake field + quick chips (Max, quick-bet bolt), total odds / stake, potential win in text.positive, and the Place bet two-row primary button.

Open questions
