Modal

tokens/components/modal.tokens.json · generated — the CSS below is generated from the same resolved tokens driving every preview on this page, not hand-copied. Colors are CSS custom properties, not literal hex.

Native <dialog>Real showModal() — free focus-trap, Escape-to-close, ::backdrop, top-layer (no z-index). This demo is genuinely interactive.
Centering is freeUnlike Drawer, no positioning CSS needed at all — showModal()'s own UA stylesheet already centers a <dialog> via position:fixed + inset:0 + margin:auto.
radius.xlAlready named for exactly this case in radius's own legend ('modals, large panels, hero cards') — not a new choice.
Nested modalsA modal opened from within another modal 'just works' via the browser's native top-layer stacking — the z-index.tokens.json modal-2/modal-overlay-2 tiers were designed for a non-native implementation and aren't needed here.
Native close<form method="dialog"> around each action button, same as Drawer.
Click-outsideNot native — showModal() only gives Escape for free. A small script (below) closes on backdrop click, same as Drawer.
Header/footer optionalSame composition philosophy as Card/Drawer — a Modal can be body-only. Each section is its own full-width band with its own padding, so the divider spans the whole modal edge to edge.
Real button statesClose (×) and the footer actions are genuine interactive elements — the same fill.neutral/fill.neutralHover/fill.neutralActive/fill.danger recipe Button itself uses, not unstyled placeholders.
AlertDialogRadix's term for a behavioral variant, not a visual one — same tokens, but no close (×), no click-outside, no Escape. For confirmations critical enough that an accidental dismiss would be bad. Use sparingly; most confirmations don't need it.

Open script

The only JS needed to open — focus-trap/Escape/::backdrop are native, same reasoning as Drawer.

document.querySelectorAll('[data-modal-open]').forEach((btn) => {
  btn.addEventListener('click', () => {
    document.getElementById(btn.dataset.modalOpen).showModal();
  });
});

Click-outside-to-close

showModal() doesn't give this for free — same gotcha and same fix as Drawer. Skips any dialog marked data-alert.

document.querySelectorAll('dialog.modal').forEach((dlg) => {
  dlg.addEventListener('click', (e) => {
    if (e.target === dlg && !dlg.hasAttribute('data-alert')) dlg.close();
  });
});

AlertDialog: blocking Escape

<dialog> fires a native cancel event right before Escape would close it — preventDefault() stops it. Only attached to data-alert dialogs; a plain Modal never sees this listener and keeps closing on Escape as normal.

document.querySelectorAll('dialog.modal[data-alert]').forEach((dlg) => {
  dlg.addEventListener('cancel', (e) => e.preventDefault());
});
