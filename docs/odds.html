Odds

tokens/components/odds.tokens.json · the coefficient value and its live movement. Generated — colours are --tok-* custom properties, never literal hex. The previews below loop the up/down flash so you can see it; in the product the app adds the modifier once per price change.

Statictext.default, tabular-nums, any string — decimal (2.83) or fractional (199/200). Not a parser.
MovementOn a new price the app toggles .odds--up / .odds--down: the value flashes text.positive / text.negative, the previous price shows struck-through (text.secondary) beside it, then one CSS animation eases the colour back to text.default and fades the old value out over movement.duration (3000ms).
Count-upAlongside the flash the value rolls from the previous price to the new one — a small requestAnimationFrame tween (~15 lines, no library) shipped with the component, over movement.countDuration (600ms). Decimal odds only; fractional (199/200) just flash. tabular-nums keeps the width steady as digits change.
PlacementThe struck-through previous value sits to the right of the new value by default; --prev-left flips it to the left — used where the odds is pinned to a right edge (the bet-card compact line, betbuilder) so the new value stays at the edge.
Trigger vs. componentThe component owns the colours, the strike, the timing and the count tween; the app owns only the trigger (oddsPlay(el) on each tick, drop the previous-value node on animationend). The looping in these demos is docs-only.
Reduced motionprefers-reduced-motion: no flash — the changed value simply holds its up/down colour with the previous value shown, so the movement is still legible without animation.
SizeContextual — 14px (heading-base) here and on a bet card; override font-size for a larger summary value. The component fixes only the numeric styling + movement.

CSS

:root {
  --tok-text-default: #FFFFFF;
  --tok-text-positive: #00A828;
  --tok-text-negative: #F90643;
  --tok-text-secondary: #8E929F;
  --tok-family-sans: 'Rubik', sans-serif;
}

.odds { display: inline-flex; align-items: baseline; gap: 6px; font-family: var(--tok-family-sans); font-weight: 500; font-size: 14px; line-height: 1.4; font-variant-numeric: tabular-nums; white-space: nowrap; color: var(--tok-text-default); }
.odds__value { color: inherit; }
.odds__prev { color: var(--tok-text-secondary); text-decoration: line-through; }
/* previous-value placement: default is to the RIGHT of the new value; --prev-left flips
   it to the left (for odds pinned to a right edge — compact line, betbuilder — so the new
   value stays at the edge and the old value extends inward). Markup order stays value→prev. */
.odds--prev-left .odds__prev { order: -1; }

/* static / prefers-reduced-motion: the changed value simply holds its up/down colour */
.odds--up .odds__value { color: var(--tok-text-positive); }
.odds--down .odds__value { color: var(--tok-text-negative); }

/* live: flash to the movement colour, then ease back to default over movement.duration; the previous value fades out */
@keyframes odds-up { 0%, 60% { color: var(--tok-text-positive); } 100% { color: var(--tok-text-default); } }
@keyframes odds-down { 0%, 60% { color: var(--tok-text-negative); } 100% { color: var(--tok-text-default); } }
@keyframes odds-prev-out { 0%, 60% { opacity: 1; } 100% { opacity: 0; } }
@media (prefers-reduced-motion: no-preference) {
  .odds--up .odds__value { animation: odds-up 3000ms ease forwards; }
  .odds--down .odds__value { animation: odds-down 3000ms ease forwards; }
  .odds--up .odds__prev, .odds--down .odds__prev { animation: odds-prev-out 3000ms ease forwards; }
}
