assets/icons/ui/*.svg · Turbo Sportsbook UI icon set · 62 icons — the product's interface glyphs (search, close, arrows, betslip / odds / live / favorites, cards, etc.)

SourceThe Turbo Sportsbook UI set, exported from Figma at 20px. This is the interface icon library components pull from (Button, Input, Select, Search, Pagination, Menu, Chip, …); the sport-discipline glyphs live on their own Discipline icons page.
ColorMonotone glyphs are recolored to fill="currentColor" on import, so the wrapper's CSS color themes them — previewed here at icon.default (#8E929F). A few are intentionally multi-tone and keep fixed brand colors: red-card, yellow-card, globe (gradient).
SizeAuthored on a 20px grid — scale via CSS width/height, the paths stay crisp at typical UI sizes (16–24px).
