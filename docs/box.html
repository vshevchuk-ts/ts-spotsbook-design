Box

tokens/components/box.tokens.json · generated — the CSS below is generated from the same resolved tokens driving every preview on this page, not hand-copied. Colors are CSS custom properties, not literal hex.

Lowest-level primitiveA generic container exposing surface/border/padding directly, no fixed combination — Card is built on top of it by picking one specific combination for content grouping.
No statesPurely presentational — same as Separator, a plain container never reacts to hover/focus/press on its own.
SurfaceEvery semantic surface role except disabled (a component-state concept, not a layout choice): page/default/sunken/overlay.
BorderOn/off only (border.default) — not a role choice like Input's, since Box isn't an interactive field.
RadiusNot re-declared — the full existing radius scale applies as-is, shown below on a real Box.
PaddingA curated 5-step subset of the dim scale (none/xs/sm/md/lg) — enough for a generic container; anything more specific can still reach dim.* directly.
