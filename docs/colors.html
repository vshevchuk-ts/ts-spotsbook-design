Colors — primitives

The Turbo Sportsbook primitive set, baked to the Pro theme. This is a fixed, Theme-Editor-driven palette — no 25→950 ramp. In the live product the Theme Editor rewrites base and status as CSS variables at runtime; sub is derived from them by opacity. Everything above (semantic, components) aliases these. tokens/primitives/color.tokens.json · generated — don't hand-edit hex.

base — surfaces

The neutral elevation stack (Theme Editor → Surfaces). Page is darkest; each step up is lighter. surface-6 is a fill/outline colour, not a background.

base.surface-0 #11141C

Main background — the page. Darkest surface, everything else sits on top. Theme Editor: 'Surfaces → Main background'.

base.surface-2 #1C202B

Cards & popups — the first elevation above the page. Theme Editor: 'Surfaces → Cards & popups'.

base.surface-4 #282E3E

Sub elements — filled inputs, secondary/sub buttons, chips. Theme Editor: 'Surfaces → Sub elements'.

base.surface-6 #3E4351

Borders, hairlines, outline-button borders, hover fills. A fill/outline color, NOT a page background — use as a background only for genuine exceptions (e.g. the score chip). Theme Editor: 'Surfaces → Borders & hover'.

base — text & brand

secondary/contrast are the two text colours; active-1/active-2 are the active colour (flat + gradient stops); accent is the secondary brand pop. All editable in the Theme Editor.

base.secondary #8E929F

Secondary text & icons — the one muted grey (there is no separate 'muted' step; secondary covers both). Theme Editor: 'Text → Secondary text'.

base.contrast #FFFFFF

Primary text & icons — maximum contrast on the dark surfaces. Theme Editor: 'Text → Primary text'.

base.active-1 #FB8C33

Active color — flat usage (text, icons, borders) AND the gradient START. Theme Editor: 'Active elements → Text, borders, icons' / gradient start.

base.active-2 #FB8C33

Active gradient END. Split from active-1 only because Figma cannot store a gradient in one variable; equal to active-1 when the theme has no gradient (as in Pro). Theme Editor: 'Active elements → gradient end'.

base.accent #31A8FF

Secondary accent / brand pop — distinct from the active color (in Pro: active is orange, accent is blue). Theme Editor: 'Brand & accent → Secondary accent'.

status

positive/negative/warning are editable in the Theme Editor; color-4..7 are extra bet-status hues set only via an imported theme file.

status.positive #00A828

Win / positive / gains. Editable in the Theme Editor ('Brand & accent → Positive').

status.negative #F90643

Lose / negative / errors. Editable in the Theme Editor ('Brand & accent → Negative').

status.warning #FFC12E

Warning / cashout / needs-attention. Editable in the Theme Editor ('Brand & accent → Warning').

status.color-4 #00BAAF

Extra bet-status hue (Pro: teal). Meaning is assigned at the semantic layer (half-win). Theme Editor ignores it — set only via an imported theme file.

status.color-5 #FF601B

Extra bet-status hue (Pro: orange). Semantic meaning: half-lose. File-only, not in the Theme Editor.

status.color-6 #AB35FF

Extra bet-status hue (Pro: purple). Semantic meaning: refund. File-only, not in the Theme Editor.

status.color-7 #A1A1A1

Extra bet-status hue (Pro: grey). Semantic meaning: pending. File-only, not in the Theme Editor.

absolutes

Theme-independent. Note: the darken/shadow steps below build on surface-0 (the page colour), not on pure black.

white #FFFFFF

Pure white — theme-independent. Base for the sub.white-* lighten steps.

black #000000

Pure black — theme-independent. NB: the darken/shadow steps use surface-0 (the page color), NOT this, so hover/shadow reads as 'toward the page' rather than muddy true-black.

sub — opacity washes

Derived by opacity: 12% colour tints, black darken/shadow steps (on the page colour), white lighten steps. Shown split — left over the page colour (real look), right on a checkerboard to reveal transparency.

sub.active-2 rgba(251, 140, 51, 0.12)

active-2 @ 12% — active tint wash. Freebet label, selected/active background.

sub.accent-2 rgba(49, 168, 255, 0.12)

accent @ 12% — accent tint wash. Live label.

sub.positive-2 rgba(0, 168, 40, 0.12)

positive @ 12% — positive tint background.

sub.negative-2 rgba(249, 6, 67, 0.12)

negative @ 12% — negative/error tint background.

sub.warning-2 rgba(255, 193, 46, 0.12)

warning @ 12% — warning tint background.

sub.black-2 rgba(17, 20, 28, 0.12)

surface-0 (page color) @ 12% — darken/shadow step 1. Overlay for pressed states & the softest shadow.

sub.black-4 rgba(17, 20, 28, 0.24)

page color @ 24% — darken/shadow step 2.

sub.black-6 rgba(17, 20, 28, 0.5)

page color @ 50% — darken/shadow step 3, also the modal/drawer scrim.

sub.black-8 rgba(17, 20, 28, 0.8)

page color @ 80% — darken/shadow step 4, the heaviest.

sub.white-2 rgba(255, 255, 255, 0.12)

white @ 12% — lighten step 1. Hover overlay on dark surfaces, inactive counter background.

sub.white-4 rgba(255, 255, 255, 0.24)

white @ 24% — lighten step 2.
