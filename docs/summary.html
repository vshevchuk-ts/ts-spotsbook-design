Summary

tokens/components/summary.tokens.json · the betslip footer totals — a key-value row list, and the three footer layouts (Single / Combo / System) composed from it plus the real Input, Select and Odds components. Generated — colours are --tok-* custom properties, never literal hex.

RowThe reusable part — .summary__row: label (text.secondary) left, value (bold, tabular-nums) right. --win = positive/green value; --turbo = active/orange value with the rocket; an optional info icon on the label opens a Tooltip.
ValuesPlain ($500.00), a range (7.02-10.00), or the Odds component (total-odds movement — struck-through old + new, prev-left).
Composed, not restyledThe stake field is Input (lg) + a Max chip; the System-Combination is Select (lg); total-odds is Odds. Summary owns only the rows; everything else is its own component.
Three footersSingle (stake-for-all + total/​win) · Combo (stake + max-bet hint + turbo row + total-odds movement + win) · System (System-Combination select + stake + range total-odds/win). The Place-bet button and footer icon buttons are separate.
