Checkbox

tokens/components/checkbox.tokens.json · generated — the CSS below is generated from the same resolved tokens driving every preview on this page, not hand-copied. Colors are CSS custom properties, not literal hex.

Native inputA real <input type="checkbox"> stays in the DOM, visually hidden (clip-rect, not display:none) — keyboard/forms/screen-readers work for free. Only the box is repainted, driven by :checked/:disabled/:focus-visible on the real input.
Single size20px box, 4px radius — no sm/base/lg grid, per explicit spec (this is a fixed-size control, not a field).
Glyphscheck.svg (checked) / remove.svg (indeterminate) from the shared Material icon set — not bespoke assets.
Unchecked ≠ disabledUnchecked default sits on surface.default (not filled), so disabled's surface.disabled swap is an actual visible change — unlike Input, where those two already share the same gray.100 value.
Statesdefault / hover / focused / checked / checked+hover / indeterminate / disabled / disabled+checked. No error state — not asked for, and there's no field validation concept here.
GroupsCheckboxGroup composes plain Checkbox items under an optional heading + helper text, vertical or horizontal — no group-level error state.
