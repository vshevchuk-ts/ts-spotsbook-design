Switch

tokens/components/switch.tokens.json · generated — the CSS below is generated from the same resolved tokens driving every preview on this page, not hand-copied. Colors are CSS custom properties, not literal hex.

Native inputA real <input type="checkbox"> stays in the DOM, visually hidden (clip-rect, not display:none) — keyboard/forms/screen-readers work for free, same approach as Checkbox/Radio.
Single size36×20px track, 16px thumb, 2px inset on every side — no sm/base/lg grid, same rationale as Checkbox/Radio.
Always filledUnlike Checkbox/Radio, the track is a solid fill even when off (surface-6) — every reference checked (Radix/MUI/Ant/iOS) draws it this way, since the track itself is the whole affordance, not just an outline.
No indeterminateCheckbox-specific tri-state concept — no switch equivalent.
No shadow on the thumbFlat white circle, no drop shadow — consistent with the rest of this system having no shadow/elevation token; contrast against the track color alone provides definition.
Statesdefault / hover / focused / checked / checked+hover / disabled / disabled+checked. No error state — not asked for.
